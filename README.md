## Selected projects

### [VMerger](https://github.com/Chaapa/VMerger)

A self-hosted video editor controlled through chat. Role-specific models produce structured plans; FFmpeg renders them into versioned films. Private S3 storage, PostgreSQL job leases and parent-version checks protect publication when jobs are retried or edits overlap.

Python · FastAPI · PostgreSQL/pgvector · FFmpeg · React/TypeScript · Docker

Single-owner alpha. Service integrations use real media tools and deterministic provider fixtures; live-model editing quality is still to be evaluated.

### [E-CUP Quality](https://github.com/Chaapa/e-cup-ozon)

An ML competition solution with LoRA training, out-of-fold scoring and a CatBoost selector. Includes training code, derived validation artifacts, integrity manifests and reproduction guides. Full retraining requires the organizer dataset.

Python · Qwen · LoRA · CatBoost · OOF validation

### [Synthetic voice detection](https://github.com/Chaapa/term-work)

A coursework notebook exploring binary classification of real and generated speech using the Deep Voice dataset.

### [Russian word stress prediction](https://github.com/Chaapa/rucode_d)

A RuCode 2023 solution for predicting stress placement in Russian words, with a notebook and notes on the model-complexity constraint.
